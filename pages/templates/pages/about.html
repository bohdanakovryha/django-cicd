Про проєкт

Після кожного push у гілку main GitHub Actions автоматично:

  • завантажує код із репозиторію;
  • встановлює залежності;
  • запускає тести;
  • якщо тести успішні — збирає Docker image;
  • відправляє image у Docker Hub;
  • запускає контейнер і перевіряє, що сайт відповідає.
